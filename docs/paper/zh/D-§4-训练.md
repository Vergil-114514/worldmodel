# 4 训练

我们分两个主要阶段训练 Cosmos 3。第一，Reasoner（推理器）在大规模图文与视频-文本语料上进行预训练，随后在精选的 Physical AI 数据混合上进行微调，从而产出用于视觉理解与推理的强大多模态骨干网络。由于 Reasoner 与 Generator（生成器）共享同一套 transformer 模块（block）架构，训练好的 Reasoner 权重随后被用来初始化 Generator，把语义与世界知识迁移进一个能够合成像素、音频与动作的模型。Generator 采用渐进式多阶段课程（curriculum）进行训练：首先进行大规模图像、视频与音频预训练，随后通过中期训练（mid-training）逐步引入动作与迁移（transfer）数据；最后，在规模更小、经过精心筛选的 Physical AI 数据集上进行后训练（post-training），以改善下游行为、物理一致性与动作保真度。

## 4.1 推理器训练

Cosmos 3 Reasoner 分两个阶段训练：先进行大规模多模态预训练，然后在精选的 Physical AI 任务上进行监督微调（supervised fine-tuning）。在预训练期间，模型从大规模图文与视频-文本语料中学习通用多模态表征。监督微调随后将模型专门化到 Physical AI 领域，包括机器人、自动驾驶与智能基础设施应用，同时保留预训练阶段获得的广泛能力。

### 4.1.1 预训练

Reasoner 预训练从一个语言模型和一个 ViT 编码器出发，二者通过一个多模态投影器（projector）相连。在初始化方面，我们同时尝试了附录 D 中描述的内部预训练模型与开源的 Qwen3-VL 模型：Edge 模型使用我们内部预训练的模型，Nano 模型使用 Qwen3-VL-8B，Super 模型使用 Qwen3-VL-32B。与此前通过只训练投影器、冻结其余 VLM 参数来完成单独对齐阶段的做法（Bai et al., 2025a）不同，我们发现这种分阶段对齐并无必要，而是从预训练一开始就联合训练所有组件。

模型在 Sec. 3.1.1 描述的大规模多模态语料上，以下一个 token 预测（next-token prediction）目标进行训练。我们在完整预训练混合数据上训练两个 epoch，使用不放回（no-replacement）采样器均匀拼接所有数据集。由于许多 Physical AI 应用要求高效推理与低延迟推理，我们把训练限制在至多 $16$k 个 token 的序列上，其中每样本的上限为 $2048$ 个图像 token 与 $8192$ 个视频 token。

沿用先前工作（Bai et al., 2025a; Wang et al., 2025e），我们对逐 token 损失施加平方根归一化的加权，以平衡短序列与长序列的贡献。我们发现这一归一化策略显著提升了下游基准分数与整体训练稳定性。

优化使用 AdamW：语言模型与投影器的峰值学习率为 $5{\times}10^{-5}$，ViT 为 $5{\times}10^{-6}$。所有学习率均遵循余弦衰减（cosine decay）调度，在 $10\%$ 的线性 warm-up 阶段之后衰减至峰值的 $0.1{\times}$。我们使用 Adam 系数 $(\beta_{1},\beta_{2})=(0.9,0.999)$。训练另外使用 $0.05$ 的权重衰减（weight decay），以及全局范数阈值为 $1.0$ 的梯度裁剪（gradient clipping）。

### 4.1.2 监督微调

为使模型适配下游 Physical AI 任务，我们在精选的高质量多模态混合数据上进行监督微调。与预训练中各数据集跨 epoch 均匀采样不同，监督微调采用一种重要性感知（importance-aware）的采样策略，其中每个数据集依据其重要性、质量与规模被分配一个固定的采样预算。这使得优化能够聚焦于高价值的下游任务，同时保持跨领域与跨能力的多样性。

为防止下游专门化削弱模型的通用推理与视觉理解能力，我们还额外混入经过滤的高质量预训练数据子集，并采用固定的 1:4 预训练-SFT 采样预算比。保留少量预训练数据流可提升鲁棒性、保持指令遵循行为，并在多个基准上维持强大的通用领域能力。我们还在监督微调混合数据中加入一个轻量级指令遵循数据集（800K 样本），以在任务适配期间进一步稳定对话与指令遵循能力。

训练共进行 8200 次迭代，全局批大小（global batch size）为 512。我们使用 AdamW 优化器：语言模型与投影器的峰值学习率为 $1{\times}10^{-5}$，ViT 为 $1{\times}10^{-6}$。所有学习率均遵循余弦衰减调度，在 $1000$ 步线性 warm-up 之后衰减至峰值的 $0.1{\times}$。我们使用 Adam 系数 $(\beta_{1},\beta_{2})=(0.9,0.95)$。我们使用 $0.1$ 的权重衰减，以及全局范数阈值为 $1.0$ 的梯度裁剪。

## 4.2 生成器训练

Cosmos 3 Generator 采用渐进式多模态课程进行训练，旨在跨不同分辨率、时长与条件模态，联合建模视觉、听觉与动作条件下的世界动态。该训练配方强调可扩展性、高保真生成与高效的长上下文学习。在预训练阶段，模型从涵盖图像、视频与音频的大规模数据中学习一般性生成先验。其后的训练阶段逐步引入更丰富的多模态监督，包括动作与迁移（transfer）序列，使模型学习到时间上连贯的世界演化与物理基础扎实的交互。

#### 训练目标。

Cosmos 3 generator 在所有模态上以 rectified flow matching（整流流匹配）目标进行优化。对来自任意模态的目标隐变量（latent），我们通过直线插值 $x_{\sigma}=\sigma\cdot\epsilon+(1-\sigma)\cdot x_{0}$ 构造带噪隐变量，其中 $x_{0}$ 为干净目标，$\epsilon\sim\mathcal{N}(0,I)$，$\sigma\in[0,1]$ 为噪声水平。单个去噪器 $v_{\theta}(x_{\sigma},\sigma,c)$ 通过带掩码的均方误差训练，以预测恒定速度 $v^{*}=\epsilon-x_{0}$，其中条件 token（\eg，图生视频任务中的干净条件帧）被门控排除在损失之外。我们施加逐模态的时间采样，即噪声水平 $\sigma$ 对每个模态（图像、视频、音频与动作）独立抽取。遵循 Waver（Zhang et al., 2025c），图像、音频与动作批次使用 logit-normal 噪声分布，视频批次使用 mode sampling（模式采样）。我们发现使用 mode sampling 能带来更好的生成质量。我们进一步通过 rectified-flow 移位（shift）重参数化把 $t$ 映射为 $\sigma=s\cdot\bar{t}/(1+(s-1)\cdot\bar{t})$，其中 $\bar{t}=1-t$，$s\geq 1$ 使边际分布偏向更高的噪声。

### 4.2.1 预训练

在预训练阶段，我们联合训练模型，以在不同分辨率与生成任务上生成图像、视频与音频。为支撑这一点，我们采用多分辨率训练策略，并在多个生成任务上联合优化模型，包括 Text-to-Image（文生图）、Text-to-(Video+Audio)（文生视频+音频）、Image-to-(Video+Audio)（图生视频+音频）与 Video-to-(Video+Audio)（视频生视频+音频）。

#### 多分辨率训练。

我们不锁定单一输出分辨率，而是同时在三个分辨率档位（256p、480p、720p）、五种宽高比以及可变帧数上进行训练，如 Tab. 5 所示。这使模型得以接触高保真内容，同时促使表征与分辨率无关。训练数据相应地划分：256p 数据流取自全部数据集（所有原生分辨率均可入选），480p 数据流仅限原生分辨率不低于 480p 的源素材，720p 数据流只使用不低于 720p 的内容，从而在最高档位保留锐度与精细细节。每个分辨率档位施加不同的最大帧数预算：256p 与 480p 至多 400 帧，720p 为 300 帧。我们把 720p 限制为 300 帧是出于序列长度约束。训练批次在四个档位上按 1:1:2:1 的比例组合，分别对应 image-only、video-256p、video-480p 与 video-720p 样本。我们发现这一分布在高保真学习与样本多样性之间提供了很强的平衡，使模型既能观察到更多训练样本，又强调更高分辨率的内容。我们使用分辨率自适应的 shift 值：256p 时 $s=1$，480p 时 $s=3$，720p 时 $s=5$。

#### 训练模式。

对于形状为 $C\times T\times H\times W$ 的隐变量视频张量，记 $T_{\textrm{cond}}$ 为条件隐变量帧数，$T_{\textrm{noised}}$ 为带噪隐变量帧数（$T=T_{\textrm{cond}}+T_{\textrm{noised}}$）。训练时，前 $T_{\textrm{cond}}$ 帧不施加任何噪声，充当条件输入；仅对其后 $T_{\textrm{noised}}$ 帧加噪，并由模型学习去噪。$T_{\textrm{cond}}$ 与 $T_{\textrm{noised}}$ 的不同取值产生不同的训练模式。我们使用四种生成模式——Text-to-Image、Text-to-Video、Image-to-Video 与 Video-to-Video——它们仅以每个样本前置的条件视觉帧数区分，采样比例分别为 $20\%$、$56\%$、$16\%$ 与 $8\%$。所有模式都使用 Sec. 3.2 描述的结构化 JSON caption 格式。

- • *Text-to-Image（T2I，文生图）。* 图像被视为时间维限制为 $T=1$ 的视频特例。在该模式下，图像从全部三个分辨率档位与各种宽高比中随机抽取，随后进行序列打包再送入模型。由于单个图像样本产生的 token 远少于视频，一条典型序列包含的样本数远多于其视频对应物。

- • *Text-to-Video（T2V，文生视频）。* 在文生视频训练中，$T_{\textrm{cond}}=0$。模型学习仅以文本为条件对整段视频去噪。除 caption 外，模型还接收时长、FPS 与时间戳元数据，作为 JSON caption 中的附加字段，使其能够生成指定长度与时间跨度的视频。

- • *Image-to-Video（I2V，图生视频）。* 对于单帧条件（$T_{\textrm{cond}}=1$），第一个隐变量帧保持干净，其后各帧被加噪。模型学习生成与初始帧及 caption 都一致的未来帧。

- • *Video-to-Video（V2V，视频生视频）。* 对于多帧条件（$T_{\textrm{cond}}=2$），模型以视频的前五帧（等价于前两个隐变量帧）为条件，学习预测与条件帧及输入提示词都一致的未来帧。

#### FPS 调制。

我们以不同的 FPS 值训练模型，因此 token 之间的物理时间间隔在不同样本间存在差异：以 30 FPS 采样的片段在真实时间上比同样 token 数以 16 FPS 采样的片段帧间更密。为反映这一点，我们调制 3D MRoPE 位置编码的时间轴——按真实世界时间而非 token 索引成比例地赋予时间坐标（见 Sec. 2），基准速率为 24 FPS。时长与 FPS 也会被追加到文本提示词中，使模型在推理时能够以特定的时间特性为条件。

#### 优化。

生成器预训练期间只更新生成专用参数。Reasoner 塔保持冻结，以保留语言与视觉理解能力。我们使用 FusedAdamW，学习率 $10^{-4}$，$(\beta_{1},\beta_{2})=(0.9,0.99)$，权重衰减 $0.05$，梯度裁剪范数 1.0。学习率调度遵循带 warmup 的线性衰减，在 $n$ 次迭代内从峰值学习率降至 $0.30\times$ 的下限。为支持 classifier-free guidance（CFG），我们在全部模态上使用 $10\%$ 的文本 dropout 率。

#### 训练 token 数。

在预训练阶段，Cosmos3-Nano 使用 $1024$ 块 NVIDIA GB200 GPU 训练了 $31.05$T 个 token，而 Cosmos3-Super 使用 $2048$ 块 NVIDIA GB200 GPU 训练了 $17.86$T 个 token。

### 4.2.2 中期训练

中期训练弥合了大规模预训练与下游部署之间的鸿沟。此时 Generator 已从大规模数据中学到一般的图像、视频与音频生成，但目标 Physical AI 应用要求对罕见动态、具身场景、控制接口与高质量视觉领域有更强的覆盖。因此我们从预训练 checkpoint 继续训练，使用一个精心构建的混合数据集，既保留原有的视觉生成模式，又引入新的监督来源。该阶段有两个互补的目标：*领域专门化* ，即增加对高价值 Physical AI 领域的暴露，以及 *多模态整合* ，即把模型从视觉与音频生成扩展到以动作和控制为条件的世界建模。

#### 领域专门化。

在保留通用知识的同时，让模型接触高度精选的专门数据集，以提升应用关键型 Physical AI 场景中的质量与可靠性。对图像，我们使用一个 15.6M 样本的中期训练池，侧重高质量真实图像，同时加入合成与文字渲染数据以拓宽概念覆盖并保持可读文字的生成。对视频，我们纳入 74.7M 条经筛选的片段，涵盖机器人、自动驾驶、人类活动、物理与合成仿真数据。这些来源针对的是通用网络级预训练中代表性不足的失效模式，例如长时程交互、细粒度的人类与机器人运动、物理对象动态，以及安全关键的驾驶或仓储场景。通过把这些领域聚焦的数据集与既有的图像和视频训练模式混合，中期训练在不丢弃预训练期间所学到的宽泛视觉先验的前提下提升了 Physical AI 相关性，如 Sec. 3.2.1 所述。

#### 多模态整合。

中期训练把 Generator 从图像、视频与音频生成扩展为一个统一的 Physical AI 模型，使其能够同时消费并合成动作与控制信号。我们对 T2I、T2V、I2V 与 V2V 沿用预训练中使用的干净前缀/带噪目标表述，因此现有视觉能力保持激活，同时新的模态专用 token 被引入扩散子序列中。这使得动作、音频、控制与视频 token 共享 Sec. 2 所述的同一时间坐标系与双向注意力模式。除预训练模式之外，我们新增两大类多模态监督：动作（action）与视频迁移（video transfer）。

- • *动作（Action）。* 我们使用采用 Sec. 2.1.3 统一动作表示的成对文本-视频-动作训练数据。模型不仅学习以动作为条件预测未来视频，还要从观测到的轨迹中推断动作，以及联合生成动作与视觉未来。这教会 Generator 在可控干预与世界演化之间建立因果接口。

- • *视频迁移（Video transfer）。* 我们加入以控制为条件的迁移数据：将干净的控制信号作为输入，模型对相应的目标图像或视频去噪。控制信号包括来自高质量视频语料的边缘（edge）、模糊（blur）、深度（depth）与分割（segmentation）图，以及用于驾驶场景的世界场景图（world-scenario map）。这让模型接触到空间上落地的约束，同时保留文本条件与视觉生成质量。

#### 多分辨率训练。

与预训练类似，中期训练在固定 74K 上下文窗口内跨 256p、480p 与 720p 进行多分辨率训练。为更好地处理动态并减少时间与高分辨率伪影，我们把 rectified-flow shift 值提高为：256p 用 $3$，480p 用 $5$，720p 用 $10$。

#### 训练目标。

与预训练类似，所有模态均使用 rectified flow 目标。对动作，我们继承视觉的噪声调度。中期训练的总损失是逐模态速度 MSE 之和，并按模态专属损失系数加权，其中动作损失乘以 $10\times$ 系数，以补偿归一化动作向量逐元素 MSE 较小的问题。

#### 优化。

与预训练类似，我们使用 FusedAdamW，学习率 $10^{-4}$，权重衰减 $0.05$，梯度裁剪范数 1.0，loss scale 为 10。学习率采用 LambdaLinear 调度，起始因子 $0.4$，循环长度 $100{,}000$。

#### 训练 token 数。

在中期训练阶段，Cosmos3-Nano 模型使用 $1024$ 块 NVIDIA GB200 GPU 训练了 $2.4$T 个 token，而 Cosmos3-Super 模型使用 $2048$ 块 NVIDIA GB200 GPU 训练了 $1.9$T 个 token。

### 4.2.3 文生图后训练

为展示 Cosmos3-Super 的全模态（omnimodal）能力，我们进一步把模型专门化为一个文生图 checkpoint——Cosmos3-Super-Text2Image。我们的目标是将模型具有物理基础的世界理解迁移到高质量图像生成，力争取得强劲的开源 T2I 结果，同时提升物理合理性与场景级对齐。

我们采用两阶段 SFT 进行文生图专门化，遵循通用的文生图基础模型训练范式：先强调语义增强，再进行偏好导向的精炼。

- • *阶段 1：广泛的 T2I 专门化。* 我们在精选的高质量 SFT 数据集上微调模型 20k 训练步。训练混合按受控比例采样：$45\%$ 通用真实图像数据、$40\%$ 合成图像数据、$15\%$ 仅文字渲染数据，以平衡视觉保真度、caption 对齐与语言保留。我们使用 $1\times 10^{-4}$ 的基础学习率、2k 次 warmup 迭代，以及线性学习率衰减调度，同时使所有其他超参数与 Cosmos 3 中期训练阶段保持一致。

- • *阶段 2：高质量精炼。* 我们使用 $470$k 对精心筛选的超高质量图像-caption 对，进行最后一轮 2k 步的 SFT。该阶段进一步提升视觉美感、提示词遵循、文字渲染质量以及与人类偏好的对齐。

- • *分辨率与上下文长度。* 两个阶段均使用 70k token 的固定上下文窗口，且只在分辨率高于 720p 的图像上训练。

总体而言，Cosmos3-Super-Text2Image 在语义对齐与英文文字渲染基准上都取得了强劲的文生图结果。在 UniGenBench 上，它在被评估的模型中取得最佳总分，完整基准达到 $91.36$（见 Tab. 11）。配合 agentic 工作流，该模型在 Artificial Analysis Text-to-Image 排行榜（Sec. 6.2.1）上位列开源权重模型第一。这些结果表明，从 Cosmos 3 出发进行下游 T2I 模态适配极为有效：它在提升场景级提示词对齐的同时，保留了模型具有物理基础的生成能力。

### 4.2.4 图生视频后训练

图生视频（Image-to-Video）能力对于全面的视觉理解具有根本性的重要意义。它检验模型对物理规律、物体恒存性与复杂场景几何的理解，同时作为具身 AI 与机器人规划的关键预测机制——模拟合理的未来帧可形成一个有效的世界模型（Wiedemer et al., 2025; Chen et al., 2025a）。尽管 Cosmos 3 的固有设计即可原生处理多种任务，我们仍利用 SFT 显式展示并专门化其在 I2V 领域的潜力。为展示这些能力，我们采用如下流程：

- • *数据与训练混合。* 我们使用经过滤、并针对更均衡的主题多样性加以精炼的预训练数据来微调模型，再通过一个 agentic 工作流进行增强：该工作流识别模型的薄弱点，并据此从预训练集中检索针对性样本。上述数据与 1,000 条高质量人工精选视频，以及一个约 20k 条、覆盖多样主题的合成视频片段数据集（约占总 token 数的 6%）组合使用。虽然所有视频序列都仅以 I2V 表述训练，我们的训练混合还包含 20% 的 T2I 图像 token，以保持模型的语义对齐。

- • *分辨率与时长。* 我们将模型的时间生成能力专门化到目标分辨率 480p 与目标时长 189 帧，约相当于 24fps 下的 8 秒。这一配置在推理速度与时间上下文之间取得平衡，从而在有意义的时间跨度上实现快速且物理合理的视频生成。

- • *训练日程。* I2V 后训练阶段运行 10k 次迭代，学习率为 $1\times 10^{-5}$。模型在整个 SFT 过程中处理约 50B 个 token。

通过后训练，Cosmos3-Super-Image2Video 在图生视频生成上达到领先质量。特别地，该模型在 Artificial Analysis Image-to-Video 排行榜（Sec. 6.2.2）上位列开源权重模型第一。关于该模型的使用细节，请参见 Sec. 6.3.1。

### 4.2.5 机器人策略后训练

我们开展机器人策略后训练，以探究 Cosmos 3 全模态世界模型能否被扩展为强大的机器人策略模型。中期训练使 Cosmos 3 能够对多模态序列——包括语言、视觉观测与动作——进行建模，并联合生成动作与视频。我们进一步通过引入本体感知（proprioceptive）信号、降低推理延迟，并让模型适配生成可执行动作以实现闭环控制，从而将其定制用于机器人策略学习。

作为先导研究，我们选用 DROID 机器人平台与数据集（Khazatsky et al., 2024），原因在于其流行度与广泛的社区采用。DROID 平台使用一台 Franka Panda 7 自由度（7-DoF）机械臂，配备 Robotiq 2F-85 平行夹爪，在多样的真实世界环境中执行桌面操作任务。DROID 数据集包含 76k 条轨迹、350 小时交互数据、86 项任务与 564 个场景，为真实世界机器人策略学习提供了可观的规模与广泛的任务多样性。我们以 360$\times$640 的高分辨率接入 DROID 数据，应用社区提供的空闲帧过滤与失败演示移除，并在训练中使用随机图像增强。

我们从中期训练得到的 Cosmos3-Nano 模型恢复训练，对 Cosmos3-Nano-Policy-DROID 进行后训练，并使用新初始化的动作编码器、动作解码 MLP 与动作嵌入 token。我们对动作相关参数施加 5$\times$ 的学习率倍率，以促进更快的适配。策略输入由当前本体感知的机器人状态与三视角视觉观测组成。具体地，原始分辨率为 360$\times$640 的腕部视角图像置于上方，其下是原始分辨率各为 180$\times$320 的两张外部视角图像，分别并排拼接在左下与右下。所得画布为 540$\times$640。策略训练预测 32 个未来的绝对关节位置动作，并附带辅助 RGB 视频帧作为额外输出，运行频率为 15Hz。在该后训练研究中，我们使用官方 DROID 短任务指令作为提示词。我们使用 $2\times 10^{-4}$ 的学习率，其余超参数沿用中期训练设置。

推理时，我们以 4 个扩散步对模型采样，并使用 shift 为 5 的移位噪声调度。我们还施加具有 CFG 并行的 classifier-free guidance，引导尺度（guidance scale）为 3，并跳过视频隐变量解码以进一步降低推理开销。这些优化共同带来显著的推理加速，使策略服务器可部署在 2 块 NVIDIA RTX Pro 6000 GPU 上。下游关节位置控制器基于 Franky（Schneider, 2023）实现，以 15Hz 执行预测出的 32 个动作。

总体而言，Cosmos3-Nano-Policy-DROID 在机器人策略任务上取得了强劲的结果。如 Sec. 6.2.5 所述，在我们提交排行榜之时，它在 RoboLab（Yang et al., 2026a）、RoboArena（Atreya et al., 2025）与 MolmoSpaces（Kim et al., 2026）上均排名第一，证明了 Cosmos3 作为机器人策略学习基础模型骨干的有效性。
